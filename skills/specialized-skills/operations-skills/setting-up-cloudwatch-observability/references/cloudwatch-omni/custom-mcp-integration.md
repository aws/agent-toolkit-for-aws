# Custom MCP servers are not supported in CloudWatch Omni

Customers cannot add their own MCP tool server to CloudWatch Omni. There is no console
screen for it, and the underlying integration type is not enabled for customer use, so a
registration attempt is refused rather than accepted.

When someone asks to register, connect, or authenticate a custom MCP server, tell them
plainly that CloudWatch Omni does not offer this and stop. Do not describe a setup flow,
and do not substitute another integration (Slack or otherwise) as if it were an MCP server.
