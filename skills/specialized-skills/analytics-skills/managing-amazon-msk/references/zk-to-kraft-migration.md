# In-place ZooKeeper-to-KRaft migration

Amazon MSK supports in-place ZooKeeper-to-KRaft migration for eligible MSK Provisioned clusters.

Before advising or acting, the agent MUST read and cite the [Amazon MSK migration Developer Guide](https://docs.aws.amazon.com/msk/latest/developerguide/zk-to-kraft-migration.html) at response time and answer the user from its published content; use the [launch announcement](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-msk-zk-kraft-migration/) and [AWS Big Data Blog](https://aws.amazon.com/blogs/big-data/announcing-in-place-zookeeper-to-kraft-cluster-upgrades-for-amazon-msk/) only for launch context, and do not copy prerequisites or procedures into this bundled reference.
