# When to offer each option

Read this before the approval pause (`references/full-loop.md`, HARD RULE #2). The
default run uses none of the options below. Offer one only in its row's case, with what
it says to show. An option you do not offer stays off; never put one into
the plan yourself. When the user asks for an option by name, explain its row and run
it only after their approval of it (HARD RULE #4).

| Option | Offer when | Show at the pause | Otherwise |
|---|---|---|---|
| Guideline judge (`review_labels.py --judge-model-id`, `references/label-review.md`) | the free checks and trial run leave a rule-based spec's conflicts unexplained, or the user asks | the judge model and rows, the `--estimate-only` job's token estimate and dollar cost (output at `output_tokens_total_with_reserve` when given: a ceiling; billed, not reversible), that it is a second opinion not shown to find more conflicts than the free checks, and no held-out gain is measured for it | the free checks only |
| Golden-row review (`golden_review.py`, `references/label-review.md`) | the user asks to check the golden rows | after the `--scope golden` job, how many rows it routed to a person (each a human decision); that this holds the corpus run, no held-out gain is measured for it, a relabeled row leaves the scored test rows, and `splits/test.jsonl` is never written (the original split undoes it) | the test split as it is |
| Stated confidence (`CONFIDENCE_METHOD = stated`) | not offered until a held-out gain is measured for it | (on the user's request) that no held-out gain is measured for it, and the extra output tokens per row as labeling dollars per 1,000 rows; one-time $0 | the jury's vote share |
| Opt-in confidence options (`CONFIDENCE_METHOD = verbalized`, `CONFIDENCE_ESTIMATOR` with `JUDGE_MODELS`, `CONFIDENCE_FLOOR_BYPASS`, `CONFIDENCE_RECALIBRATION`; `references/apply-and-confidence.md`) | not offered: no held-out gain is measured for it | (on the user's request) that no held-out gain is measured for it; what it changes (one model instead of the jury, a judge's score, the floor dropped or moved); calls per row (1 instead of the jury's N, plus 1 per judge, each judge call about the labeler's prompt and reply in input tokens) and their cost per 1,000 rows, uncached and cached; with recalibration, the one-time dollar cost of labeling the fit rows once more; with a judge or panel, the judge-failure limit (`references/troubleshooting.md`, Judge failures over the share) | the jury's vote share |
| In-job search (`OPTIMIZER = '{"Mode": "protegi", "Elicitation": "plain"}'`, `references/spec-refinement.md`, In-job search) | not offered: no gain is measured for it on the customer's held-out seed test rows (its val gain is chosen on val) | (on the user's request) that no held-out gain is measured; before the run, the one-time dollar cost (about `10*val + 21*min(dev, 32) + 42*min(dev, 64)` labeled rows and 63 teacher calls, and worker retries add up to `42*min(dev, 32)` rows and 126 teacher calls; `references/spec-refinement.md`, Cost of the in-job search; at the labeler's per-1,000-row cost and the teacher's on-demand token price), billed and not reversible; after it, the `Optimizer` block and the per-1,000 cost of the pick's extra bytes on every later row (`offer.picked_bytes` minus `offer.incumbent_bytes` in `optimizer_result.json`, about 4 bytes a token) | the incumbent spec |
| Reply-keys line (a hand edit after the trial run, under the spec's Output Schema block: "When the reply format the job appends has more keys (such as `confidence`), give them too.") | stated confidence is chosen and the trial run prints `STATED CONFIDENCE MISSING` (`references/troubleshooting.md`, Stated confidence missing) | that it adds output tokens on every labeled row, with the extra tokens per row and their labeling cost per 1,000 rows, and that it is not shown to raise coverage or lower the missing share | the spec without the line |
| Extra or stronger jurors (`JURY_MODELS`) | the gold seed is small (200 to 400 rows) | that no held-out gain is measured for it; each added model's labeling cost per 1,000 rows; one-time $0 | the default jury |

Unless its Offer-when case says otherwise (the reply-keys line, extra jurors), an option
whose gain is not measured on this seed stays off: say so, and go on.
