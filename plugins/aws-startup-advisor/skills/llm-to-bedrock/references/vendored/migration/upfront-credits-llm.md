# Apply for AWS migration credits

Get $1,500 in AWS Promotional Credits for your migration when you create an assessment. Migrating a larger workload? You may be eligible for more. Talk to your AWS representative. Final eligibility determined by AWS.

Visit [AWS Startups Migrate](https://startups.aws.com/startups/en-US/migrate/credits?source=plugin) to get started. Unlike infrastructure or mixed assessments, this standalone LLM migration does not currently create an uploadable `plan.json`; do not expect a plan file from this flow.
