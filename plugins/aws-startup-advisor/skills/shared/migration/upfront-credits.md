# Apply for AWS migration credits

Get $1,500 in AWS Promotional Credits for your migration when you create an assessment. Migrating a larger workload? You may be eligible for more. Talk to your AWS representative. Final eligibility determined by AWS.

An infrastructure or mixed GCP or Heroku migration assessment produces a `plan.json` file. When the assessment is complete, upload that file through [AWS Startups Migrate](https://startups.aws.com/startups/en-US/migrate/credits?source=plugin) to see whether you qualify.
