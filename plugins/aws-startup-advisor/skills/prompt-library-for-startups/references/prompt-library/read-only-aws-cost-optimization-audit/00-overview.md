## AWS Cost Optimization Audit: Eight-Phase Read-Only Spend Review

Audit an AWS account or organization for waste, rightsizing, and commitment opportunities, working from the bill rather than a service checklist. Strictly read-only: every remediation is written up for a human to run, never executed. Reports what it could not check as carefully as what it found.
