## AWS Bill Shock Preventer

This agent scans your AWS account for cost risks like idle resources, untagged infrastructure, and missing budget alerts, then generates cleanup commands and right-sizing recommendations to cut waste.

## About this agent

<!-- markdownlint-disable -->

Surprise AWS bills are one of the most common pain points for startups. This agent runs a 4-phase scan of your AWS account — cost trends, zombie resources, right-sizing opportunities, and governance gaps — to surface everything silently inflating your monthly spend.
