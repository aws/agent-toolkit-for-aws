## Kiro Strands AgentCore Agent

A Kiro CLI agent equipped with tools, MCP servers, and a knowledge base to help you build AI agents using Strands and Amazon Bedrock AgentCore following best practices.

## About this agent

<!-- markdownlint-disable -->

Build production-ready AI agents on AWS with expert guidance built in. This Kiro CLI agent is pre-configured with Strands and Amazon Bedrock AgentCore best practices — including steering files, MCP server integrations, and an optional local knowledge base powered by official AWS sample repos. Ask it to scaffold a new agent, explain AgentCore concepts, or generate a full agent app with a chatbot UI, and it produces code that follows AWS patterns out of the box. No need to read docs first — the agent already knows them.
