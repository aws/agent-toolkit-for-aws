# Workshop assumption sheet

Show only bounded knobs that preserve the frozen resource set: target region, availability, compute management model, cost posture, CPU architecture, and a confirmed selector preference that does not bypass an eliminator. Never offer an AWS product directly for database, disk, worker, cron, or Workflow decisions; the inner selector recomputes the winner.

Show baseline and active scenario, changed preference paths, capacity-preserving and right-sized known-cost floors, unpriced-line count, and recommendation outcome. State that all AWS rates remain on the us-east-1 cache basis; a non-us-east-1 scenario receives a `region_note`, not a fabricated regional multiplier. `calculator_url` is always null. Offer Apply and reprice, Compare, Exit, or explicit full-Clarify re-entry.
