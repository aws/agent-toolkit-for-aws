Decision summary

Proceed in phases with the selected managed AWS targets. Current Render spend is $123.45 monthly; the capacity-preserving AWS known-cost floor is $352 monthly and the right-sized floor is $290 monthly. EFS remains unpriced, so neither total is a ceiling.

Architecture

The design uses build-once immutable promotion through ECR, managed PostgreSQL and Valkey, Fargate for direct task control, a private service-discovery path with no public load balancer, and CloudFront for static content. Project and environment boundaries become tagged, isolated network and deployment stacks.

Data migration

Verify PostgreSQL version, extensions, source privileges, and connectivity before selecting AWS Database Migration Service for full load and CDC. Monitor lag, perform writer quiescence, apply the final delta, run row-count and checksum integrity checks, then switch connections. Validate Valkey persistence and eviction semantics without capturing values. Keep explicit source retention until sign-off.

Storage migration

Create the encrypted EFS access point for /var/data; verify ownership, permissions, locking, latency, and capacity. Run a pre-copy, then writer quiescence and a final delta. Compare the integrity manifest before remounting. Retain the source disk for rollback.

Deployment migration

Build once and push one immutable ECR digest, then promote that digest without rebuilding. Record the serving deploy identity separately from the newest deploy, preserve auto-deploy state, and retain rollback lineage before shifting any environment.

Cutover

Confirm prerequisites and certificate readiness, lower external DNS TTL in advance, freeze releases, establish writer quiescence, apply the final data deltas, shift traffic gradually, and hold the maintenance window until acceptance checks pass.

Rollback

Use error rate, integrity, and lag as rollback triggers. Fence target writers before restoring the retained Render source writer, restore DNS and traffic, preserve target evidence, and honor the source retention window. Never allow two PostgreSQL primaries.

Verification

Check public and static endpoint responses, private endpoint reachability, database read/write and counts, cache eviction behavior, disk ownership and locking, worker drain/idempotency, cron overlap/retry behavior, image digest identity, and Workflow callback/state behavior manually.

Deferred surfaces

deferred_shared_ai_engine: infrastructure can proceed, but AI model, adapter, estimate, and generation remain deferred and resume from the provider-neutral profile.

conditional_workflow_generation_unsupported: the selected Step Functions Standard and Lambda targets are design outputs only; callback, compensation, retry, and state-retention semantics require manual tests, so no Workflow Terraform was fabricated.

Accounting

Assumptions and limitations

AWS pricing is a reviewed cache basis; EFS is unpriced. Workflow generation tests do not yet establish callback, compensation, retry, and state-retention parity. Apply is prohibited until provider-backed Terraform validation, source connectivity, migration rehearsal, and owner approval complete.
