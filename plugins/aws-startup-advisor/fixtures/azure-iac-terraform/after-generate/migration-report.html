Architecture Overview ↑ contents

Discovery grouped the estate into five workload clusters. No pattern catalog was on disk for this run, so each cluster carries its target shape as a rationale, not a named architecture pattern — the report does not claim architectural insight it does not have.

Web workload (rg-app + rg-data) — the priced core

One workload spanning two resource groups: the S1 App Service Plan and its five web apps are one compute unit, and the storefront app addresses the Postgres Flexible Server and the Redis cache through app settings, which is what merged the groups. The VNet, its two subnets, the route table, the Bastion host, the Key Vault and the two observability resources attached here because they carry no primary resource of their own. Becomes: one Elastic Beanstalk environment on the plan's capacity, one RDS PostgreSQL instance, one ElastiCache Valkey cluster, one MSK cluster, in one VPC with the source address space (10.20.0.0/16) preserved.

Function workload (rg-app)

A second compute unit with no relationship to the web workload: the Y1 consumption plan, its one function app, the storage account that function addresses, and the SMB file share in that account. Becomes: Lambda for the function, S3 for the blob surface, FSx for Windows File Server for the SMB share.

Catalog store (rg-data)

The Cosmos DB account is a workload of its own — nothing in the estate references it. Becomes: one Amazon DocumentDB cluster, because the account's API is Mongo.

Reporting VM (rg-shared)

The Windows reporting VM and its NIC, with the IoT Hub attached as an edgeless fragment. Becomes: one EC2 instance (m6i.xlarge, Windows Server 2022, License Included) with a gp3 root volume; the IoT Hub is deferred to a specialist engagement.

Idle plan (rg-shared) — a cost finding, not a workload

A single P1v3 Windows App Service Plan with zero apps on it. It is money being spent with no workload behind it, and it is raised as a cost-optimization finding. Carried as: an Elastic Beanstalk environment flagged idle, so the decision to drop it is yours and visible.
