# Deploy Base Model Plan

**Recommended for:** Users who want to deploy a base model as-is without fine-tuning. The user does not have a trained model and wants to select and deploy directly from the SageMaker Hub catalog.

1. **Define Use Case** — Capture the business problem, users, and deployment constraints. _(Reference: use-case-specification)_
2. **Select Base Model** — Filter the catalog by constraints and choose a model. _(Reference: model-selection)_
3. **Verify Environment** — Check SDK version, region, and execution role are configured. _(Reference: sdk-getting-started)_
4. **Deploy Model** — Create an endpoint for the selected base model. _(Reference: model-deployment)_
